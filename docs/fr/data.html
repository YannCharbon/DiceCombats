Vos données

Vos créatures, vos combats et vos réglages sont conservés sur votre appareil ou, sous Windows, dans le dossier de votre choix. Cette page décrit comment les partager avec d'autres MJ, comment DiceCombats les sauvegarde et comment utiliser les mêmes données sur plusieurs ordinateurs.

Partage

Lorsque vous exportez un combat avec Exporter en fichier, le fichier contient aussi les créatures qu'il utilise, telles qu'elles figurent dans votre liste de créatures. La personne qui l'importe dispose ainsi de toute la rencontre, prête à être jouée.

Exporter les créatures et Exporter les combats enregistrent une liste complète dans un seul fichier. Dans les Réglages, section Données, Exporter toute la bibliothèque… enregistre en une seule fois vos créatures, combats, groupes de joueurs, champs personnalisés et automatisations.

Les jetons d'accès de vos automatisations ne sont jamais exportés. Un message invite la personne qui importe le fichier à les saisir de nouveau.

Importer un fichier

Le bouton Importer depuis un fichier… se trouve dans la liste des créatures, dans celle des combats et dans les Réglages. Il ouvre également les fichiers exportés par les versions précédentes de DiceCombats.

  1. Cliquez sur Importer depuis un fichier… et choisissez le fichier.
  2. Lorsque rien dans le fichier ne figure déjà dans votre bibliothèque, un récapitulatif présente ce qui sera ajouté. Sinon, vous décidez du sort de chaque élément, comme expliqué ci-dessous.
  3. Cliquez sur Importer. DiceCombats sauvegarde d'abord vos données, puis importe le fichier et indique ce qui a été ajouté, remplacé ou laissé de côté.

Décider du sort de chaque élément

Lorsqu'une partie du fichier figure déjà dans votre bibliothèque, chaque élément est présenté comme Nouveau, À jour, Différent ou Nom déjà utilisé. À côté, une liste propose les choix possibles pour cet élément, avec sous elle une courte explication du choix retenu. Le choix proposé est déjà sélectionné.

  • Importer comme copie ajoute la version importée à côté de la vôtre, sous un nouveau nom. La vôtre reste inchangée.
  • Remplacer la version locale remplace votre version par celle du fichier.
  • Conserver la version locale laisse de côté la version importée ; ce qui l'utilise dans le fichier utilisera la vôtre.
  • Importer sous un autre nom ou Conserver les deux sous le même nom, lorsque seul le nom est déjà utilisé.
  • Utiliser la version locale à la place laisse de côté l'élément importé et utilise le vôtre partout où le fichier en a besoin.

Pour donner la même réponse à de nombreux éléments à la fois, utilisez le bouton situé à côté de la liste, par exemple Même choix pour les 12 créatures marquées « Différent ». Rien de ce que vous possédez déjà n'est modifié sans votre accord.

Le nom des copies

Lorsqu'au moins un élément doit recevoir un nouveau nom, une barre intitulée Noms des copies apparaît en haut de la fenêtre d'importation. Elle permet de choisir un texte placé avant le nom et un texte placé après. Par défaut, la copie de « Gobelin » s'appelle « Gobelin (2) ». Si vous modifiez ces textes, les noms proposés sont mis à jour, sauf ceux que vous avez saisis vous-même. DiceCombats ajoute toujours un numéro lorsqu'un nom est déjà utilisé. Le bouton Importer reste indisponible tant qu'un nom est vide ou déjà utilisé.

Sauvegardes

DiceCombats sauvegarde vos données à la première ouverture de chaque journée, ainsi qu'avant chaque importation, chaque restauration et chaque copie de vos données vers un autre dossier. Une sauvegarde contient vos créatures, combats, groupes de joueurs, champs personnalisés, automatisations, journaux de combat et réglages.

Les dix sauvegardes automatiques les plus récentes sont conservées. Celles que vous effectuez vous-même, ainsi que celles qui précèdent une importation, une restauration ou une copie vers un autre dossier, ne sont jamais supprimées par l'application.

Restaurer une sauvegarde

  1. Ouvrez les Réglages, section Données. La sauvegarde la plus récente y est affichée.
  2. Cliquez sur Restaurer à côté d'elle, ou sur Toutes les sauvegardes… pour voir les autres, avec leur date, l'ordinateur concerné et leur motif.
  3. Confirmez. DiceCombats sauvegarde d'abord vos données actuelles, afin que vous puissiez revenir en arrière si nécessaire, puis restaure la sauvegarde choisie.

Les sauvegardes sous forme de fichier

Enregistrer une sauvegarde dans un fichier… sauvegarde vos données dans leur état actuel et enregistre le fichier à l'emplacement de votre choix. Restaurer depuis un fichier… permet ensuite de les récupérer. Sous Windows, Ouvrir le dossier des sauvegardes affiche l'emplacement où DiceCombats conserve ses sauvegardes.

Le dossier de données

Sous Windows, la partie Dossier de données des Réglages indique l'emplacement où DiceCombats conserve vos données et permet d'en choisir un autre.

  1. Cliquez sur Choisir un autre dossier… et sélectionnez le nouveau dossier.
  2. Confirmez avec Déplacer mes données. DiceCombats effectue une sauvegarde, copie vos données dans le nouveau dossier, vérifie la copie, puis redémarre pour l'utiliser.
  3. Vos anciennes données restent à leur emplacement. Une fois que vous avez vérifié que tout se trouve dans le nouveau dossier, vous pouvez les supprimer avec Supprimer l'ancienne copie.

Revenir au dossier par défaut ramène vos données à leur emplacement d'origine. Un dossier situé dans AppData ne peut pas être utilisé, et si le dossier choisi contient déjà d'autres fichiers, DiceCombats place ses données dans un sous-dossier.

Un dossier qui contient déjà des données DiceCombats

Sur votre second ordinateur, choisissez le même dossier. DiceCombats constate qu'il contient déjà des données DiceCombats, vous indique ce qu'il renferme et ce que contient cet ordinateur, puis vous demande ce que vous souhaitez faire :

  • Utiliser les données du dossier passe au dossier tel quel. Vos données actuelles restent à leur emplacement.
  • Les remplacer par les miennes sauvegarde d'abord les données du dossier, puis les remplace par les vôtres.
  • Fusionner ajoute vos données à celles du dossier ; lorsqu'un élément existe des deux côtés, vous décidez de ce qu'il convient de faire, comme lors d'une importation.

Utiliser plusieurs ordinateurs

Sous Windows, vous pouvez conserver vos données dans un dossier synchronisé par OneDrive, Dropbox ou un autre service. Vous retrouvez ainsi les mêmes créatures et les mêmes combats sur chacun de vos ordinateurs. Merci de régler le service pour qu'il conserve toujours les fichiers de ce dossier sur l'appareil ; sinon, DiceCombats risque de devoir attendre leur téléchargement.

Un ordinateur à la fois

Merci de n'ouvrir DiceCombats que sur un ordinateur à la fois. Si vous le lancez alors qu'il est encore ouvert sur un autre ordinateur, un écran vous indique lequel et depuis quand.

  • Ouvrir quand même ouvre le dossier de données sur cet ordinateur-ci également. Si DiceCombats est encore ouvert sur l'autre ordinateur, merci de l'y fermer d'abord.
  • Quitter ferme DiceCombats sans rien modifier.

Modifications faites sur un autre ordinateur

Lorsqu'un autre ordinateur modifie vos données pendant que DiceCombats est ouvert, un message vous propose de les Recharger au moment qui vous convient. DiceCombats ne les recharge jamais de lui-même, pas même au milieu d'un combat.

Si vous modifiez ensuite un élément déjà modifié sur l'autre ordinateur, DiceCombats vous demande s'il faut Recharger, pour reprendre la version de l'autre ordinateur, ou Remplacer, pour conserver la vôtre.

Si DiceCombats est fermé avant que vous ayez fait ce choix, vos modifications sont conservées dans le dossier de données, dans un fichier dont le nom se termine par .unsaved.json. Elles vous sont signalées au démarrage suivant. Celles qui concernent les créatures et les combats peuvent être récupérées avec Importer depuis un fichier… ; la fenêtre d'importation rappelle alors l'origine du fichier. Pour les autres données, le message affiché au démarrage explique comment mettre le fichier à la place du fichier de données auquel il correspond, après avoir effectué une sauvegarde.

Messages au démarrage

Au démarrage, DiceCombats vous signale les fichiers du dossier de données qui se trouvent uniquement dans le cloud. Il vous signale également les copies créées par votre service de synchronisation lorsque deux ordinateurs ont modifié le même fichier en même temps. DiceCombats utilise les fichiers d'origine ; je vous invite à les comparer avec ces copies et à supprimer celles dont vous n'avez pas besoin.

Lorsque le dossier est inaccessible

Si votre dossier de données se trouve sur un disque externe ou sur un emplacement réseau qui n'est pas connecté, DiceCombats affiche un écran dédié plutôt qu'une bibliothèque vide. Il propose les choix suivants :

  • Réessayer, une fois le disque ou le réseau connecté ;
  • Choisir un autre dossier…, si vos données ont changé d'emplacement ;
  • Ouvrir le dossier par défaut à la place, pour cette session uniquement. Un message vous rappelle alors que vos modifications sont enregistrées dans le dossier par défaut, et non dans votre dossier de données ;
  • Quitter.

Sous Android

Le dossier de données ne peut pas être changé sous Android. Pour transférer vos données vers un autre appareil, deux possibilités s'offrent à vous :

  • Exporter toute la bibliothèque… sur le premier appareil, puis Importer depuis un fichier… sur le second ;
  • Enregistrer une sauvegarde dans un fichier… sur le premier appareil, puis Restaurer depuis un fichier… sur le second.
