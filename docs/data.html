Your data

Your creatures, combats and settings are kept on your device, or on Windows in a folder of your choice. This page explains how to share them with other game masters, how DiceCombats backs them up, and how to use the same data on several computers.

Sharing

When you export a combat with Export to file, the file also holds the creatures the combat uses, as they are in your creature list. Whoever imports it gets the whole encounter, ready to run.

Export creatures and Export combats save a whole list in one file. In Settings, in the Data section, Export the whole library… saves your creatures, combats, player groups, user custom fields and automations at once.

The access tokens of your automations are never exported. The person who imports the file is reminded to enter them again.

Importing a file

Import from a file… is available in the creature list, in the combat list and in Settings. It also opens files exported by older versions of DiceCombats.

  1. Click Import from a file… and choose the file.
  2. When nothing in the file is already in your library, a short summary shows what will be added. Otherwise, you choose what to do with each item, as explained below.
  3. Click Import. DiceCombats makes a backup of your data first, then imports the file and shows what was added, replaced or left out.

Choosing what to do with each item

When part of the file is already in your library, each item is marked New, Up to date, Differs or Name already used. Next to it, a list offers the choices that make sense for it, with a short explanation of the selected one underneath. The suggested choice is already selected.

  • Import as a copy adds the imported version next to yours, under a new name. Yours is not changed.
  • Replace the local one overwrites your version with the imported one.
  • Keep the local one leaves the imported version out. Anything imported that uses it then uses yours.
  • Import with a new name or Keep both with the same name, when only the name is already used.
  • Use the local one instead leaves the imported one out and uses yours wherever the file needs it.

To give the same answer to many items at once, use the button next to the list, for example Same choice for all 12 creatures marked “Differs”. Nothing you already have is changed without your choice.

Names of the copies

When at least one item needs a new name, a bar at the top of the import window shows Names of copies, with a text to put before the name and a text to put after it. By default, a copy of “Goblin” is named “Goblin (2)”. If you change these texts, the suggested names are updated, except the ones you have typed yourself. DiceCombats still adds a number when a name is already used, and Import stays unavailable while a name is empty or already used.

Backups

DiceCombats backs up your data the first time you open it each day, and before every import, every restore and every copy of your data to another folder. A backup holds your creatures, combats, player groups, user custom fields, automations, combat logs and settings.

The ten most recent automatic backups are kept. The ones you make yourself, and those made before an import, a restore or a copy to another folder, are never deleted by the app.

Restoring a backup

  1. Open Settings and go to the Data section. The most recent backup is shown there.
  2. Click Restore next to it, or All backups… to see the others with their date, computer and reason.
  3. Confirm. DiceCombats first backs up your current data, so that you can go back if needed, then restores the backup you chose.

Backups as files

Save a backup to a file… backs up your data as it is now and saves it where you choose. Restore from a file… brings it back. On Windows, Open the backups folder shows where DiceCombats keeps its backups.

The data folder

On Windows, Settings shows under Data folder where DiceCombats keeps your data, and lets you choose another folder.

  1. Click Choose another folder… and select the new folder.
  2. Confirm with Move my data. DiceCombats makes a backup, copies your data to the new folder, checks the copy, then restarts and uses it.
  3. Your previous data stays where it was. Once you have checked that everything is in the new folder, you can remove it with Delete the old copy.

Back to the default folder takes your data back to where it was at first. A folder inside AppData cannot be used, and if the folder you choose already holds other files, DiceCombats keeps its data in a subfolder.

A folder that already holds DiceCombats data

On your second computer, choose the same folder. DiceCombats sees that it already holds DiceCombats data, shows what is in it and what is on this computer, and asks what you would like to do:

  • Use the folder's data switches to the folder as it is. Your current data stays where it is.
  • Replace it with mine backs up the folder's data, then replaces it with yours.
  • Merge adds your data to the folder's, and you choose what to do when an item exists on both sides, as with an import.

Using several computers

On Windows, you can keep your data in a folder that OneDrive, Dropbox or another service keeps in sync. You then find the same creatures and combats on each of your computers. Please set the service to always keep the files of this folder on the device, otherwise DiceCombats may have to wait for them to download.

One computer at a time

Please open DiceCombats on one computer at a time. If you start it while it is still open on another computer, a screen tells you which one and since when.

  • Open anyway opens the data folder here as well. If DiceCombats is still open on the other computer, please close it there first.
  • Quit closes DiceCombats without changing anything.

Changes made on another computer

If another computer changes your data while DiceCombats is open, a message offers to Reload it when you are ready. DiceCombats never reloads by itself, even in the middle of a combat.

If you then change an item that was changed on the other computer, DiceCombats asks whether to Reload, which takes the other computer's version, or to Overwrite, which keeps yours.

If DiceCombats is closed before you choose, your changes are kept in the data folder, in a file whose name ends in .unsaved.json, and you are told about them at the next start. Changes to creatures and combats can be brought back with Import from a file…; the import window then reminds you where the file comes from. For the other data, the message at start explains how to put the file in place of the data file it belongs to, after making a backup.

Notices at start

When it starts, DiceCombats tells you if some files of the data folder are only in the cloud. It also tells you if your synchronisation service has made copies of files that two computers changed at the same time. DiceCombats uses the original files; please compare them with the copies and delete the copies you do not need.

When the folder cannot be reached

If your data folder is on an external drive or a network drive that is not connected, DiceCombats shows a screen instead of an empty library, with these choices:

  • Try again, once the drive or the network is connected;
  • Choose another folder…, if your data has moved;
  • Open the default folder instead, for this session only. A message then reminds you that your changes are saved in the default folder, not in your data folder;
  • Quit.

On Android

The data folder cannot be changed on Android. To take your data to another device, you can use either of these:

  • Export the whole library… on the first device, then Import from a file… on the other one;
  • Save a backup to a file… on the first device, then Restore from a file… on the other one.
